# ADSA Sorting Visualizer

An interactive web-based project that helps students understand
sorting algorithms through visual animations.

The project is developed using **HTML, CSS, and JavaScript**.

## 🚀 Features

- Enter your own numbers
- Generate a random array
- Visualize sorting step by step
- Count number of comparisons
- Count number of swaps
- Display time complexity
- Simple and user-friendly interface
- Works directly in a web browser
- Responsive design for different screen sizes

## 📚 Algorithms Included

### 1. Bubble Sort
Compares adjacent elements and swaps them when they are in the wrong order.

**Time Complexity:** O(n²)

### 2. Selection Sort
Finds the smallest element and places it in the correct position.

**Time Complexity:** O(n²)

### 3. Insertion Sort
Builds the sorted array one element at a time.

**Time Complexity:** O(n²)

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in any modern web browser.
4. Enter numbers or generate a random array.
5. Select a sorting algorithm.
6. Click Start Sorting.
7. Watch the sorting process visually.

💻 Example Input

50,20,40,10,30

The application will visualize the sorting process and display:

- Comparisons
- Swaps
- Selected algorithm
- Time complexity
